# Playwright – Web Data Collection

## Project Overview

This repository contains a practical assignment focused on web data collection using Playwright and Python.

The main goal of this project is to learn how to collect structured data from websites, automate browser interactions, and work with web pages that load content dynamically using JavaScript.

## Project Description

The project uses Playwright to collect data from a website.

The assignment focuses on:
- Browser automation using Playwright
- Working with JavaScript-rendered web pages
- Extracting structured information from web pages
- Navigating between pages
- Collecting and saving data into CSV format

## Tools & Technologies

- Python
- Playwright
- Pandas
- Jupyter Notebook
- CSV

## How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```
2. Install Playwright:
   ```bash
   pip install playwright pandas
   ```
3. Install browser dependencies:
   ```bash
   playwright install
   ```
4. Open the notebook in Jupyter Notebook.
5. Run the cells to execute the data collection process.
